## How the PM Assistant Uses This

When asked a PM question, the agent:
1. Checks this index for the most relevant file
2. Reads that file before responding
3. States which framework it drew from
4. Flags if the question falls outside what's covered here

This traceability is intentional — it's itself a PM best practice, and useful for the portfolio case study.
